히트타일 사진 업로드 도우미

사진을 넣고 정보만 채우면, 자동으로 imgbb에 올리고 구글 시트에 바로 붙여넣을 데이터를 만들어줍니다.

1. 무료 API 키 (최초 1회만)

api.imgbb.com 접속 → 구글 계정으로 로그인 → 화면의 "Get API Key" 클릭 → 나오는 키를 복사해서 아래에 붙여넣으세요. 한 번 발급받으면 계속 재사용하시면 됩니다 (매번 새로 만들 필요 없음).

2. 사진 추가

사진넘버사이즈색상태그공간

아직 추가된 사진이 없어요.

3. 이 내용을 구글 시트에 붙여넣기

아래 "결과 복사" 버튼을 누른 다음, 구글 시트에서 넘버 열의 빈 줄을 클릭하고 Ctrl+V 하시면 여러 줄이 한 번에 채워집니다.
